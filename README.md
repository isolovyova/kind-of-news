# Kind of News

A digest for people who are tired of digests. Mondays, Wednesdays, Fridays.
Every issue has four short blocks: one good thing that actually happened, one piece of history with a human detail in it, one fact you didn't know this morning, and one sentence that asks nothing of you.
Everything verified. Links at the bottom, because that part matters.

## Subscribe to Kind of News newsletter

If you are here as a reader, [subscribe to Kind of News on
Buttondown](https://buttondown.com/kindofnews). Mondays, Wednesdays, Fridays, straight to your inbox. One good thing, one curiosity, one tiny fact, one thought. No hustle, no politics, no takes.

## Start in Codex or Claude Code

Want your own private digest in a connected channel? Copy this into Codex or Claude Code:

```text
Install Kind of News from https://github.com/isolovyova/kind-of-news and start the setup tutorial.
```
## How it works

- Want to read Kind of News? [Subscribe on Buttondown](https://buttondown.com/kindofnews).
- Want your own private digest? Install the plugin in Codex or Claude Code and follow the short setup tutorial.
- Want to run the public newsletter? See the [advanced GitHub Actions setup](docs/github-actions-setup.md).
